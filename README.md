# JARVIS Mobile V1 (Native Android)

This is a real Android app project, not a website/PWA.

## V1 features
- Scan the QR generated by Desktop JARVIS Phone Link.
- Pairing token expires after 5 minutes and still requires explicit approval on the PC.
- LAN/private-address enforcement in both the Android app and PC server.
- Session token stored locally on the phone; Groq/Fish/API keys remain only on the PC.
- Mobile chat and synchronized assistant replies.
- PTT using Android SpeechRecognizer, then the recognized Turkish command is sent to the PC JARVIS brain.
- Quick commands for Film mode and TV volume/home.
- A lightweight original AURORA core visual.

## Build
Open this folder in Android Studio (JDK 17), let Gradle sync, then Build > Build APK(s).

Android SDK/Gradle are not bundled in this source ZIP. The desktop update must be installed first because V6 adds the native `/api/pair-request` endpoint and encodes native `jarvis://pair` QR payloads.

## Security note
V1 transports requests over local HTTP because self-signed TLS certificates are not practical for zero-install LAN pairing. Access is restricted to private LAN addresses and protected with random short-lived pairing tokens, explicit PC approval, and a high-entropy session token. A future version can add application-layer encryption / remote access separately.
